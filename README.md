Attendance Tracker

A simple web-based attendance tracker built with HTML, CSS, JavaScript, and JSON-server.  
This app allows users to add attendance records, view a summary, and export records as a CSV file.  

Features
- Add attendance records (Name, Date, Status).
- Fetch and store records in a JSON-server backend.
- View all records in a list.
- Attendance summary with percentage calculation.
- Export all records to CSV.
- Auto-load records from backend on page load.

Technologies Used
- Frontend: HTML, CSS, JavaScript
- Backend (Mock API):JSON-server
